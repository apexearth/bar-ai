How this AI is balanced

Everything below is a default the AI ships with, read straight out of targets.as and tunables.as. Editing a value writes the file — press Deploy before the change reaches a game. The small override box beside a knob does not touch the file: it rides along as a modoption on every game launched from this dashboard, which is the cheap way to A/B one number.

This page is the curated set. Nothing here is a hard cap or a timer — every number is a ratio against the economy, which is the rule the whole AI is built on.

What do you want to change?

Pick the thing you actually want different. Each one is an ordered recipe — try the first step alone, redeploy, and look before adding the second. Twelve changes in one session once cut this AI's metal production 4.3×, and every one of them had looked reasonable on its own.

Changed something?

A value edited above is written to the repo, not to the game. Deploy copies it into the live install, then watch a game and see what it did — five minutes of watching beats a tournament for finding out whether a change helped.

Only changing one thing at a time tells you which change did it.
